# 学生成绩管理系统

《数据结构》课程设计 —— 选题（26）学生成绩管理系统

C 语言实现，支持**浏览器图形页面**和**控制台菜单**两种运行模式，无需安装数据库或任何运行库。

## 快速开始

1. 双击 `app.exe`（或源码编译，见下文）
2. 选择 `1` 浏览器页面模式 → 自动打开浏览器页面操作（推荐）
3. 数据自动保存在 `data/students.txt`

命令行可直接 `app.exe web` 跳过菜单进入页面模式。

## 功能一览（对照指导书要求）

| 指导书要求 | 实现 |
|---|---|
| 成绩录入（批量导入 + 手动输入） | 启动时从 `data/students.txt` 加载；页面/控制台手动录入 |
| 修改 | 按学号+学期+课程修改成绩；学生基本信息统一修改 |
| 多条件查询（课程/学期/班级等） | 学号/姓名/班级/学期/课程任意组合筛选 |
| 统计分析（平均分、及格率、排名 + 图表） | 页面带排名表和成绩分布条形图；控制台输出排名表 |
| 角色权限（管理员/教师/学生） | 管理员全功能；教师无删除/信息修改；学生仅查本人 |
| 使用文件存储 | 文本文件 `data/students.txt`，一行一条 |

## 数据文件格式

```
学号 姓名 班级 学期 课程 分数
230101 张三 计科2301 2025-2026-1 高等数学 92.0
```

## 登录账号（演示用）

账号文件 `data/users.txt`（自动生成，一行一条：`账号 密码 角色 姓名`，角色 0=管理员 1=教师 2=学生），可自行增改：

| 账号 | 密码 | 角色 | 权限 |
|---|---|---|---|
| `admin` | `admin123` | 管理员 | 全部功能（录入/修改/删除/查询/统计） |
| `teacher01` | `123456` | 教师 | 录入/修改/查询/统计（无删除） |
| `230101`~`230103` | `123456` | 学生 | 仅查询本人成绩（学号即账号） |

登录采用令牌（token）机制：登录成功签发令牌，之后每个请求携带令牌，服务端校验权限；学生即使篡改前端参数，服务端也会强制只查本人数据。

## 源码编译

```bash
gcc -std=c99 -Wall -O2 -o app.exe src/main.c src/list.c src/fileio.c src/index.c src/auth.c src/webui.c -lws2_32 -lshell32 -luser32
```

## 模块结构

```
src/
├── student.h   数据结构：Student 记录（一条记录=一人一门课）、角色枚举
├── list.h/c    单向链表：插入/查找/删除/修改/统计（增删改查核心）
├── fileio.h/c  文件持久化：加载/全量保存/追加
├── index.h/c   学号哈希索引（FNV-1a，链地址法），查找 O(n)→O(1)
├── webui.h/c   内置 HTTP 服务器 + 浏览器页面（Winsock，仅本机访问）
└── main.c      入口：角色登录、控制台菜单、统计排序
```

## 页面模式接口（webui.c 内置）

| 接口 | 说明 |
|---|---|
| `/api/list` | 多条件查询 |
| `/api/add` | 录入（防重复：学号+学期+课程唯一） |
| `/api/update` | 修改成绩 |
| `/api/delete` | 删除记录 |
| `/api/stats` | 统计（人数/平均分/及格率/排名） |
| `/api/save` | 手动保存到文件 |
